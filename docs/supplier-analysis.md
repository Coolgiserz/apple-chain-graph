> 在供应链「结构图谱」之外，对苹果 60 家供应商中的 **15 家重点企业**补充基本面与估值研究。
> 目标：不仅能看到「谁供应什么」，还能评估「这家供应商自身质地如何、当前贵不贵」。

## 2. 方法论

### 2.1 数据合并（三源）

`tools/supplier_research/analysis.py` 把三块信息合并为分析数据集：

1. **`universe.py`** — 每家供应商的代码 / 交易所 / 财报币种 / 是否上市 / **sector 同业分组**。
2. **图谱 JSON**（`data/apple_supply_chain.json`）— 名称 / 类别(tier) / 国家。
3. **`supplier_fundamentals.csv`** — 基本面与估值倍数 + 趋势/近况 + **来源链接**（人工可核）。

### 2.2 相对估值引擎（`valuation.py`）

对每家上市且含倍数的供应商，计算其相对估值：

```
score = mean( P/E ÷ 同业中位(P/E),  P/B ÷ 同业中位(P/B),  EV/EBITDA ÷ 同业中位(EV/EBITDA) )
```

- `score < 0.85` → 🔵 **低估**
- `score > 1.15` → 🔴 **高估**
- 其余 → 🟢 **合理**

**同业组（sector）**：直接按 `category`（图谱细类）做同业会因样本过少（多数仅 1 家）而全部 N/A，
故改用更宽、业务可比性更强的 sector 分组（见 `universe.py` 的 `SECTOR` 字典）：
Foundry / Memory / Logic Semi / Display / OSAT / Optics / CIS·Camera / Assembly /
Enclosure / Glass·Enclosure / Battery / PCB·FPC / Components / OEM(Benchmark)。

**回退机制**：若某 sector 内可比样本（不含自身）不足以构成有效中位，则对该倍数
**自动回退到全样本中位**，并在报告明细中标注 `全样本中位(同业不足回退)`。

### 2.3 苹果基准

苹果为终端厂/客户，单独列为 `OEM(Benchmark)`，不参与供应商同业比较，仅作对照。

## 3. 数据字段字典（`supplier_fundamentals.csv`）

| 字段 | 含义 | 单位 |
|------|------|------|
| `supplier_id` | 与图谱一致的供应商主键 | — |
| `as_of` | 数据截止/核对日期 | 日期 |
| `market_cap_usd_b` | 总市值 | 十亿美元(USD bn) |
| `revenue_ttm_usd_b` | 营收(TTM) | 十亿美元 |
| `net_income_ttm_usd_b` | 净利润(TTM) | 十亿美元 |
| `gross_margin_pct` | 毛利率 | % |
| `net_margin_pct` | 净利率 | % |
| `roe_pct` | 净资产收益率 | % |
| `pe` / `pb` / `ev_ebitda` | 估值倍数 | × |
| `debt_to_equity` | 负债权益比 | ×（部分为估算，已在 trend 标注） |
| `trend` | 发展趋势（定性） | 文本 |
| `recent` | 近况（定性） | 文本 |
| `source` | 数据来源链接 | URL |

> 跨市场数值已统一换算为 USD，粗略汇率：TWD≈32、KRW≈1400、JPY≈155、CNY≈7.2、HKD≈7.8。
> 亏损企业（如 LG Display）P/E 留空；且当 TTM 净利为负时，P/B、EV/EBITDA 属困境/周期底部倍数，引擎直接判为「困境（亏损）·倍数失真」而非「低估」，并在计算同业中位时排除亏损同业，避免其失真倍数拉偏盈利同业（如京东方）。

## 5. 局限性（务必阅读）

1. **相对估值，非绝对估值**：结论来自「当前倍数 vs 同业中位」，不是 DCF 内在价值。
   倍数本身已隐含市场预期，故「高估」不代表一定该卖，「低估」也不代表一定该买。
2. **快照时点**：数值取自 2026 年 7–8 月近一个月行情快照，价格随市波动，结论属某一时点相对判断。
3. **小样本敏感**：本次仅 15 家填充基本面。Memory 组有 3 家（稳健）；
   Logic Semi / Display / Components / Assembly 各组仅 2 家（两两相对，幅度敏感）；
   Foundry / CIS·Camera / Optics / OSAT 仅 1 家（回退全样本中位）。判定方向通常合理，但幅度需谨慎。
4. **汇率近似**：跨市场统一折算 USD 用粗略汇率，宏观/汇率波动会引入偏差。
5. **定性字段**：`trend`/`recent` 为研究摘要；`debt_to_equity` 中标注「估算」者为粗略值。
6. **非投资建议**：全部内容仅用于产业链结构与基本面研究/教学，**不构成任何投资或采购建议**。

## 7. 舆情分析（另一独立维度）

除基本面/估值外，还对这 15 家做了**舆情（市场情绪）**研究，单独产出
`tools/output/supplier_sentiment.md`，并自动把基本面估值结论并排，便于识别「情绪—估值」背离。

### 7.1 字段字典（`supplier_sentiment.csv`）

| 字段 | 含义 |
|------|------|
| `supplier_id` | 与图谱/基本面一致的供应商主键 |
| `as_of` | 舆情快照日期 |
| `news_sentiment` | 新闻情绪：`positive` / `neutral` / `negative`（近期主流媒体报道基调） |
| `news_summary` | 新闻综述（定性摘要） |
| `analyst_sentiment` | 分析师情绪：`bullish` / `neutral` / `bearish`（卖方共识方向） |
| `analyst_consensus` | 分析师共识（评级分布、平均目标价与上行空间） |
| `key_catalysts` | 关键正面催化剂 |
| `key_risks` | 关键风险/隐忧 |
| `sources` | 可点击来源链接（stockanalysis 共识页、Reuters/Bloomberg/Nikkei/券商研报等） |

### 7.2 当前舆情分布（2026-08-05 快照）

| 维度 | 分布 |
|------|------|
| 新闻情绪 | 正面 12 家、中性 2 家（LG Display、康宁）、负面 1 家（高通） |
| 分析师情绪 | 看多 13 家、中性 2 家（高通、LG Display） |

### 7.3 舆情方法局限

1. **定性+共识，非量化模型**：新闻/分析师情绪为综合判断，不输出连续分数。
2. **跨市场覆盖密度差异**：美股（MU/AVGO/QCOM/GLW）分析师共识数据最完整；台/韩/日/中股以本地券商与中文财经媒体为主，口径不一。
3. **快照敏感**：目标价与情绪随股价、财报快速变化，属某一时点判断。
4. **非投资建议**：仅用于产业链研究/教学，**不构成任何投资或采购建议**。

## 8. 地理维度（生产基地 × 估值，第三独立维度）

在基本面/估值、舆情之外，新增**地理维度**：把各供应商的「生产基地/总部城市」落到地图上，
与估值判定交叉，观察供应链的**地理集中度与地缘韧性**。

### 8.1 数据产物

- `tools/data/supplier_geo.csv`：100 个地理点（15 家重点供应商的多基地明细 + 宇宙内其余主要供应商总部点），含 `region`、GCJ-02 坐标、生产内容、估值判定、市值、品类。
- `tools/visualizations/supplier_geo.html`：腾讯地图 GL JS 看板（合规：代理模式、前端零密钥、GCJ-02 坐标、台湾/南海按国家标准呈现）。标记按估值判定着色，点击弹窗看生产基地详情；右侧栏叠加洞察。进一步打通供应链图谱 edge：**① 上游连线**（蓝/红/橙，供应商基地→苹果组装厂，按估值着色，箭头指示流向）、**② 下游连线**（紫色，组装厂→终端市场 美/中/欧）、**③ 终端市场汇聚点**（金色星形标记）、**④ 流动动画**（箭头沿连线流动，可开关）。
- 生成脚本：`tools/geo_build.py`（数据源为公开资料整理的城市级近似坐标，可核；中国大陆+台湾已转 GCJ-02）。

### 8.2 关键洞察（2026-08-05 快照）

- **区域分布**：中国大陆 36、中国台湾 20、日本 13、美国 12、韩国 9、越南 3，其余（印度/马来/新加坡/欧洲）各 1。
- **大中华区暴露度 56%**（56/100 个生产基地位于中国大陆+中国台湾）——这是地缘、关税、物流集中风险的核心指标；iPhone 主力组装（郑州/深圳/成都）高度集中于中国大陆。
- **重点供应商集中度**：15 家中 **6 家单区域布局**（boe 全中国、largan 全台湾、samsung_elec 全韩国、sony 全日本，以及 fabless 的 broadcom/qualcomm 仅美国总部——后两者“单区域”是设计型无晶圆厂，其产能实际在代工厂），**9 家跨多区域**（tsmc/foxconn/micron/ase 等已在美/日/印/越/马来分散）。
- **估值 × 地理**：被「高估」组平均覆盖 2.38 个区域/家（最分散，多为 AI/HBM 景气溢价且主动出海建厂），「低估」组 1.83（相对集中），「困境」组 2.0。样本小，仅作方向性参考。
- **韧性含义**：纯制造型单区域供应商（如 boe、largan、三星电子、索尼）在地缘/自然灾害冲击下替代弹性最弱，是供应链韧性分析的重点观察对象；而台积电、富士康、美光等已推进美/日/印/越多点布局，韧性更强。

### 8.3 地理方法局限

1. **城市级近似**：坐标为城市中心级近似（非精确厂区门牌），用于区域分布与集中度判断足够，不适合精确测距。
2. **覆盖深度不一**：15 家重点供应商为“多基地明细”，其余供应商仅列总部/代表点，不全量反映其全部厂区。
3. **坐标系统**：中国大陆+台湾用 GCJ-02（腾讯地图标准）；海外按 WGS84≈GCJ-02 处理。
4. **非投资建议**：仅用于产业链结构与地缘韧性研究/教学，**不构成任何投资或采购建议**。

### 8.4 供应链物流连线（edge 打通，2026-08-06 新增）

把地图与供应链图谱的 **edge 真正打通**，形成「生产基地 → 组装 → 市场」全链路视角：

- **上游连线（供应商→组装厂）**：基于图谱 edge 链 `supplier→component→product→assembler`（`supplied_by` / `uses_component` / `assembled_by`）自动推导，共 **42 条**，覆盖 14 家重点供应商 → 4 家组装厂（郑州/桃园/东莞/潍坊）。连线按估值判定着色，箭头指示流动方向。
- **下游连线（组装厂→终端市场）**：4 家组装厂 × 3 大终端市场（美国·库比蒂诺、中国·上海、欧洲·慕尼黑）= **12 条**紫色连线。
- **终端市场汇聚点**：3 个金色星形标记，代表苹果出货的终端市场。
- **流动动画**：54 枚箭头沿连线流动（上游 42 + 下游 12），点击「▶ 流动动画」开启，可视化供应流向；另有「隐藏供应连线 / 隐藏下游连线」两个开关。
- **洞察**：大量上游连线汇聚郑州，直观印证 iPhone 主力组装高度集中、是供应链最敏感单点；全链路视图可叠加估值判定，观察“被低估的供应商仍在向高度集中的组装节点供货”这一结构性现象。
