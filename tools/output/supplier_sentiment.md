## 三、方法与局限

- **新闻情绪**：基于 2026 年近期（近数月）主流财经媒体/新闻的报道基调综合判断，分为正面 / 中性 / 负面。

- **分析师情绪**：基于卖方的评级分布与共识方向（看多 / 中性 / 看空），并给出平均目标价与上行空间（若有）。

- **数据来源**：每条均附可点击的来源链接（stockanalysis.com 分析师共识页、Reuters/Bloomberg/Nikkei/Yahoo Finance/券商研报等），可人工核验。

- **局限**：① 舆情为**定性+共识**判断，非量化模型；② 跨市场（美/台/韩/日/中）分析师覆盖密度差异大，A 股/台股部分以本地券商与中文财经媒体为主；③ 快照时点敏感，目标价与情绪会随股价与财报快速变化；④ 本分析仅用于产业链研究/教学，**不构成任何投资或采购建议**。
